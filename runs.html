The record

The system keeps its own log.

Below is the unattended run record of the flagship billing system — every cycle since the night it first ran, transcribed from the reports the run writes for itself. Counts only, published with the client’s approval: no shipment, party, or price data leaves the system.

Read it the way the system writes it: ok means nothing needed a human. to check is work the run queued for review rather than deciding alone. problems is the run saying something broke — flagged, escalated, and waited on, never guessed at. Steps grew from 12 to 22 as new slices of the operation shipped.
